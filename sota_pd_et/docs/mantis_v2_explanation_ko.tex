\begin{abstract}
이 문서는 기존에 사전학습된 시계열 Transformer인 MantisV2를
PADS 움직임 신호의 고정 특징 추출기로 사용하는 방법을 설명한다.
참가자 한 명의 132개 채널을 각각 512개 표본으로 보간한 뒤,
동결 인코더의 세 번째 Transformer 층에서 채널당 512차원 표현을 추출한다.
이를 결합한 67,584차원 벡터에 학습 폴드별 표준화와 클래스 가중 릿지 분류를 적용한다.
입력과 각 수학적 대상을 정의하고, 토큰 생성, attention, 특징 결합,
학습 목적함수, 참가자 단위 중첩 교차검증을 순서대로 기술한다.
동일한 304명과 동일한 외부ㆍ내부 분할에서 얻은 예측을 비교하면,
균형 정확도는 MultiROCKET--HYDRA의 67.13\%에서 70.89\%로,
ET 재현율은 10/28에서 12/28로 증가했다.
통합 AUROC는 0.9000에서 0.8876으로 감소했다.
따라서 이 결과는 일부 지표의 개선을 보인 탐색적 비교이며,
전반적인 우월성이나 외부 임상 타당성을 확립하지 않는다.
\end{abstract}

\section{분류 문제와 데이터의 단위}
\subsection{참가자와 정답의 정의}
참가자 인덱스 집합을 $\mathcal P=\{1,\ldots,N\}$, $N=304$로 둔다.
PADS v1.0.0의 공개 진단 문자열이 \code{Parkinson's}인 276명과
\code{Essential Tremor}인 28명을 사용한다 \cite{pads}.
각 참가자 $i\in\mathcal P$의 표적은
\begin{equation}
 y_i=\begin{cases}0,&\text{공개 진단이 PD},\\1,&\text{공개 진단이 ET}\end{cases}
 \qquad r_i=2y_i-1\in\{-1,+1\}
 \label{eq:target}
\end{equation}
이다. $y_i$는 평가용 이진 표적이고 $r_i$는 릿지 최소제곱의 표적이다.
원래 숫자 라벨 2에는 ET 외의 감별 진단도 들어가므로 그것만으로 ET를 선택하지 않는다.
진단명은 정답 생성에, ID는 자료 연결과 분할에만 사용한다.
나이, 성별, 설문, 약물과 질병 자유 서술은 특징에 넣지 않는다.
공개 PD 라벨이면서 ET 관련 설명이 있는 8명도 공개 라벨을 유지한다.

\subsection{한 참가자의 입력 행렬}
$i$번째 참가자의 입력은 $X_i\in\R^{C\times T}$,
$C=132$, $T=976$이다.
채널 $c\in\{1,\ldots,C\}$의 시계열을
$x_{ic}=(X_i[c,0],\ldots,X_i[c,T-1])^\top\in\R^T$로 정의한다.
채널 순서는
\begin{equation}
11\text{개 과제 구간}\ \times\ 2\text{개 손목}\ \times\
2\text{개 센서}\ \times\ 3\text{개 축}=132
\end{equation}
이다. 센서는 가속도계와 자이로스코프, 축은 $X,Y,Z$이다.
과제, 손목, 센서, 축 순서로 순회한 공식 배열 순서를 보존한다.
\textbf{132개 채널을 하나의 긴 시간축으로 이어 붙이지 않는다.}
다른 과제 구간은 같은 순간에 관측한 물리적 센서 채널이 아니다.
전체 배열의 크기는 $(304,132,976)$이고, 분할 단위는 언제나 참가자이다.

공식 전처리 이진 파일을 little-endian float32로 읽으며,
공식 SHA-256, 파일 크기, 유한값, 참가자 ID 중복과 진단 표/JSON 일치를 확인한다.
이 입력은 공개 연구의 과제 선택, 중력 성분 처리와 앞 48개 표본 제거 등을 이미 포함한다.
현재 파이프라인은 원시 타임스탬프를 복원하거나 시간 간격의 결손을 보정하지 않는다.

\section{전체 계산과 무엇이 학습되는가}
\begin{equation}
\boxed{X_i\ \xrightarrow[\text{채널별}]{R}\ (\R^{512})^{132}
\ \xrightarrow{\phi_{\theta_*}}\ (\R^{512})^{132}
\ \xrightarrow{\concat}\ z_i\in\R^{67584}
\ \xrightarrow{S_{\mathcal I}}\ \widetilde z_i
\ \xrightarrow{b+\beta^\top(\cdot)}\ s_i.}
\label{eq:pipeline}
\end{equation}
$R$에는 학습 모수가 없다. $\theta_*$는 외부에서 사전학습된 체크포인트 값이며,
이번 실험에서는 PADS를 이용해 갱신하지 않는다.
반면 $S_{\mathcal I}$, $b$와 $\beta$는 $\mathcal I$에 의존한다.
따라서 인코더 특징을 한 번 계산해 저장하는 것과
전체 코호트에서 표준화를 적합하는 것은 서로 다른 연산이다.
이 실험에서는 전자만 교차검증 전에 수행한다.

\section{고정 보간: 976개 표본에서 512개 표본으로}
출력 길이를 $L=512$라 하고 $u=R(x)$라 쓰자.
\code{torch.nn.functional.interpolate}의
\code{mode='linear', align_corners=False}를 사용한다 \cite{torchinterp}.
출력 인덱스 $j\in\{0,\ldots,L-1\}$가 참조하는 입력 실수 좌표는
\begin{equation}
 q_j=(j+\tfrac12)\frac{T}{L}-\tfrac12,
 \quad a_j=\lfloor q_j\rfloor,\quad \lambda_j=q_j-a_j,
 \quad u_j=(1-\lambda_j)x_{a_j}+\lambda_jx_{a_j+1}.
 \label{eq:resize}
\end{equation}
이번 $T=976,L=512$에서는 $q_0=0.453125$,
$q_{511}=974.546875$이므로 모든 참조 인덱스가 유효하다.
예를 들어 $u_0=0.546875x_0+0.453125x_1$이다.
일반적인 경계 외 좌표에는 프레임워크의 경계 처리가 적용되지만
이 크기 조합에서는 필요하지 않다.

보간에는 참가자 간 평균, 진단 라벨, 학습 단계가 없다.
다만 표본 수 감소는 시간 해상도를 바꾸며, 별도의 antialias 필터를 적용하지 않았다.
따라서 모든 고주파 정보가 보존된다고 해석하면 안 된다.
이 연산은 물리적인 샘플링 간격을 다시 추정하는 타임스탬프 재구성이 아니다.
512는 사전학습 표현과 공식 사용 지침을 따른 고정 선택이며,
이번 외부 결과를 보고 고른 값이 아니다 \cite{mantisrepo}.

\section{MantisV2: 한 채널이 특징 벡터가 되는 과정}
\subsection{고정 체크포인트와 사전학습의 의미}
모델은 \code{paris-noah/MantisV2}, 패키지는
\code{mantis-tsfm==1.1.0}이다.
저자들은 CauKer2M 합성 시계열로 사전학습했다고 보고한다
\cite{mantispaper,mantisrepo}.
이는 이번 PADS 학습과 별도의 단계이다.
전체 체크포인트의 모수는 4,188,672개이며 모두 동결한다.
이번 특징 추출은 6개 Transformer 블록 중 앞 3개를 통과한 뒤 반환한다.
체크포인트 전체 모수 수와 실제 통과하는 블록 수는 구분해야 한다.
사전학습 투영 헤드 \code{prj}는 이 특징 추출 출력에 사용하지 않는다.

이하에서는 하나의 보간된 채널 $u\in\R^{512}$만 생각한다.
설명을 위해 참가자와 채널 첨자 $i,c$를 잠시 생략한다.
이 절의 모든 선형 계수, 합성곱 계수, 정규화 계수와 CLS 토큰은
체크포인트에 저장된 고정 값이다.

\subsection{원신호ㆍ차분 경로와 원래 크기의 통계 경로}
길이 $L=512$의 1차 차분을 다음과 같이 정의한다.
\begin{equation}
 d_j=\begin{cases}u_{j+1}-u_j,&0\le j\le510,\\0,&j=511.\end{cases}
 \label{eq:diff}
\end{equation}
마지막 0은 오른쪽에 붙이는 패딩이며 순환 차분이 아니다.
각 $v\in\{d,u\}$를 채널 내부에서 별도로 표준화한다.
\begin{equation}
 \bar v=\frac1L\sum_{j=0}^{L-1}v_j,\quad
 s(v)=\sqrt{\frac1{L-1}\sum_{j=0}^{L-1}(v_j-\bar v)^2},\quad
 \mathcal N(v)_j=\frac{v_j-\bar v}{s(v)+10^{-5}}.
 \label{eq:internalnorm}
\end{equation}
내부 \code{torch.std}는 보정값 1을 사용하므로 분모는 $L-1=511$이다.
여기서 분모의 $10^{-5}$는 제곱근 바깥에 더한다.

동시에 $P=32$개의 비중첩 패치
$J_a=\{16a,\ldots,16a+15\}$, $a=0,\ldots,31$에 대해
\begin{equation}
 \mu_a=\frac1{16}\sum_{j\in J_a}u_j,\qquad
 \sigma_a=\sqrt{\frac1{15}\sum_{j\in J_a}(u_j-\mu_a)^2}
 \label{eq:patchstats}
\end{equation}
를 계산한다. $\mu_a,\sigma_a$는 \emph{보간된 원신호}에서 계산하며
$\mathcal N(u)$에서 계산하지 않는다.
따라서 모양 경로는 표준화하지만 크기 정보는 별도 경로로 전달한다.
입력을 미리 참가자별 단위 분산으로 바꾸면 이 통계 경로의 정보도 바뀐다.
이번 실험에서 외부 입력 z-score를 추가하지 않은 이유이다.

\subsection{합성곱 경로의 256차원 패치 표현}
$v\in\{d,u\}$의 표준화 신호에 커널 길이 41, 출력 차원 256의
서로 다른 1차원 합성곱을 적용한다.
시간 방향 양쪽에 20개의 0을 패딩하므로 출력 길이는 512이다.
\begin{equation}
 h^{(v)}_{j,k}=b^{(v)}_k+
 \sum_{\ell=0}^{40}W^{(v)}_{k,\ell}\,
 \overline{\mathcal N(v)}_{j+\ell-20},
 \quad 0\le j<512,\quad1\le k\le256,
\end{equation}
여기서 위쪽 막대는 정의역 밖 값을 0으로 연장한다는 뜻이다.
이는 PyTorch의 cross-correlation 인덱스 규약으로 쓴 식이다.
각 시점의 256개 성분에 LayerNorm을 적용하고 패치 안에서 평균한다.
\begin{equation}
 g^{(v)}_a=\frac1{16}\sum_{j\in J_a}\LN_{10^{-5}}(h^{(v)}_j)
 \in\R^{256}.
\end{equation}
여기서 차원 $d_{\mathrm n}$의 벡터 $h\in\R^{d_{\mathrm n}}$에 대한
LayerNorm을 다음과 같이 정의한다.
\begin{align}
 m(h)&=\frac1{d_{\mathrm n}}\sum_{k=1}^{d_{\mathrm n}}h_k,\\
 \LN_\epsilon(h)&=\gamma\odot
 \frac{h-m(h)\bm1}
 {\sqrt{d_{\mathrm n}^{-1}\sum_{k=1}^{d_{\mathrm n}}(h_k-m(h))^2+\epsilon}}
 +\delta,\qquad \gamma,\delta\in\R^{d_{\mathrm n}}.
\end{align}
$\bm1\in\R^{d_{\mathrm n}}$는 모든 성분이 1인 벡터이고,
$\odot$는 성분별 곱이다. 각 정규화 모듈마다 별도의 고정 affine 계수
$\gamma,\delta$가 있다. 위 합성곱 경로에서는 $d_{\mathrm n}=256$이다.
분산의 분모는 $d_{\mathrm n}$이며 $\epsilon$은 제곱근 안에 더한다.
한 벡터의 성분 방향 통계이므로 학습 코호트 전체나 다른 참가자의 통계가 아니다.

\subsection{통계 경로와 토큰 생성}
스칼라 $a_0\in\R$를 32차원으로 보내는 다중 척도 인코더를
$E_\mu,E_\sigma:\R\to\R^{32}$라 하자.
구현에서 척도는 $\mathcal K=\{10^{-4},10^{-3},\ldots,10^4\}$이고,
각 경로는 별도 가중치를 갖는다.
\begin{align}
 \rho_\kappa(a_0)&=
 \frac{\left|1/\log(|a_0|/\kappa+1.1)\right|}
 {\sum_{\eta\in\mathcal K}\left|1/\log(|a_0|/\eta+1.1)\right|},\\
 E(a_0)&=\sum_{\kappa\in\mathcal K}\rho_\kappa(a_0)
 \LN_{10^{-15}}(a_0w_\kappa+\kappa b_\kappa),\quad
 w_\kappa,b_\kappa\in\R^{32}.
\end{align}
여기서 $E$를 $E_\mu$ 또는 $E_\sigma$로 해석한다.
LayerNorm의 affine 계수도 각 인코더에 포함한다.
이렇게 만든 $a$번째 패치 토큰은
\begin{equation}
 t_a=\LN_{10^{-15}}\!\left(
 A\begin{bmatrix}g^{(d)}_a\\g^{(u)}_a\\E_\mu(\mu_a)\\E_\sigma(\sigma_a)\end{bmatrix}
 +a_*\right)\in\R^{256},\qquad A\in\R^{256\times576}.
 \label{eq:token}
\end{equation}
따라서 $576=256+256+32+32$이다.
$a_*\in\R^{256}$는 고정 절편이며 패치 인덱스 $a$와 다른 대상이다.

\subsection{Transformer가 패치 사이의 관계를 계산하는 방법}
사전학습된 CLS 벡터 $t_{\mathrm{cls}}\in\R^{256}$를
32개 패치 \emph{뒤에} 추가한다.
\begin{equation}
 H^{(0)}=\begin{bmatrix}t_0^\top\\\vdots\\t_{31}^\top\\t_{\mathrm{cls}}^\top\end{bmatrix}
 \in\R^{33\times256}.
\end{equation}
각 블록은 pre-normalization 잔차 구조이다.
$\ell=0,1,2$에 대해
\begin{align}
 U^{(\ell)}&=H^{(\ell)}+
       \operatorname{MHA}_{\ell}(\RMS_{\ell,1}(H^{(\ell)})),\\
 H^{(\ell+1)}&=U^{(\ell)}+
       \operatorname{FFN}_{\ell}(\RMS_{\ell,2}(U^{(\ell)})).
 \label{eq:block}
\end{align}
RMSNorm은 각 행 $h\in\R^{256}$에 대해
\begin{equation}
 \RMS(h)=g\odot\frac{h}{\sqrt{256^{-1}\sum_{k=1}^{256}h_k^2+10^{-8}}}
\end{equation}
이며 고정 척도 $g\in\R^{256}$를 갖는다.
각 블록의 두 정규화는 서로 다른 $g$를 사용한다.

MHA는 8개 head를 사용하고 head당 차원은 $d_h=32$이다.
정규화된 입력 $V\in\R^{33\times256}$의 선형 투영으로
각 head $h$의 $Q_h,K_h,V_h\in\R^{33\times32}$를 만든다.
구현의 RoPE/XPos 위치 변환을 query와 key에 적용한 결과를
$\widehat Q_h,\widehat K_h$로 표기하면,
\begin{align}
 A_h&=\softmax_{\mathrm{row}}\left(
       \widehat Q_h\widehat K_h^\top/\sqrt{32}\right)\in\R^{33\times33},\\
 O_h&=A_hV_h\in\R^{33\times32},\qquad
 \operatorname{MHA}(V)=\concat_{h=1}^{8}(O_h)W_O+b_O.
\end{align}
여기서 $W_O\in\R^{256\times256}$이다.
위치 변환의 수치 규약은 고정 패키지의 \code{rope.py}를 그대로 사용한다.
위 식은 그 연산을 생략한 것이 아니라 $\widehat Q_h,\widehat K_h$에 포함해 쓴 것이다.
causal mask가 없으므로 한 채널의 모든 패치와 CLS가 서로를 참조할 수 있다.
이 attention은 \textbf{한 채널 내부}에서만 수행된다.

FFN은 중간 폭 512의 SwiGLU이다.
입력 행 $v\in\R^{256}$를 두 512차원 벡터로 보내는
$a(v),b(v)$와 최종 affine 변환 $B$를 사용하면
\begin{equation}
 \operatorname{FFN}(v)=B\bigl(\silu(a(v))\odot b(v)\bigr),
 \qquad \silu(x)=\frac{x}{1+e^{-x}}
\end{equation}
이다. 곱과 SiLU는 성분별 연산이다.
평가 모드에서는 attention과 FFN의 dropout이 꺼져 있다.
미래값을 생성하는 예측 디코더나 PD/ET 전용 신경망 헤드는 사용하지 않는다.

\subsection{세 번째 층과 combined 표현}
\code{return_transf_layer=2}는 0부터 센 층 번호이므로 $H^{(3)}$를 반환한다.
CLS 행을 $h_{\mathrm{cls}}=H^{(3)}[32,:]^\top$,
패치 행 평균을 $\bar h=32^{-1}\sum_{a=0}^{31}H^{(3)}[a,:]^\top$라 하면
\begin{equation}
 \phi_{\theta_*}(u)=\begin{bmatrix}h_{\mathrm{cls}}\\\bar h\end{bmatrix}
 \in\R^{512}.
 \label{eq:embedding}
\end{equation}
즉 \code{combined}는 CLS와 \emph{CLS를 제외한} 패치 평균의 결합이다.
층과 출력 방식은 공식 권고를 따른다 \cite{mantisrepo,mantiscode}.
이번 PD/ET 외부 폴드 점수를 비교하여 고른 층은 아니다.

\section{채널 결합, 표준화와 릿지 분류}
\subsection{참가자 특징의 결합과 표현력}
채널 첨자를 복구하면
\begin{equation}
 e_{ic}=\phi_{\theta_*}(R(x_{ic})),\qquad
 z_i=\begin{bmatrix}e_{i1}\\e_{i2}\\\vdots\\e_{i132}\end{bmatrix}\in\R^{67584}.
 \label{eq:concat}
\end{equation}
배치 계산 시 $(N,C,T)$를 $(NC,1,T)$로 재배열하지만,
이는 독립 채널을 효율적으로 묶는 것이다. 시간축을 연결하지 않는다.
출력을 원래 참가자ㆍ채널 순서로 복원한다.
이번 전체 특징 행렬 $Z\in\R^{304\times67584}$는 float32이다.

고정 인코더는 채널 간 attention을 하지 않는다.
릿지 점수도 채널 특징에 대한 가법적 선형 결합이므로,
채널 간 비선형 상호작용이나 위상 동기화가 자동으로 학습된다고 주장할 수 없다.
채널별 특징의 기여를 함께 조합하는 것과 비선형 교차 채널 모델링은 다르다.

\subsection{학습 집합에서만 적합하는 StandardScaler}
현재 학습 집합을 $\mathcal I$, 크기를 $n=|\mathcal I|$로 두고,
특징 좌표를 $k\in\{1,\ldots,p\}$로 둔다.
\begin{equation}
 m_{\mathcal I,k}=\frac1n\sum_{i\in\mathcal I}z_{ik},\qquad
 v_{\mathcal I,k}=\frac1n\sum_{i\in\mathcal I}(z_{ik}-m_{\mathcal I,k})^2.
\end{equation}
표준화는
\begin{equation}
 \widetilde z_{ik}=
 \frac{z_{ik}-m_{\mathcal I,k}}{a_{\mathcal I,k}},\qquad
 a_{\mathcal I,k}=\begin{cases}
 \sqrt{v_{\mathcal I,k}},&\text{일반적인 비상수 특징},\\
 1,&\text{수치적으로 상수로 판정한 특징}
 \end{cases}
 \label{eq:scaler}
\end{equation}
이다. 실제 상수 판정은 \code{StandardScaler}의 수치 허용 규약을 따른다.
분산의 분모는 $n$이며 \code{ddof=0}이다 \cite{scaler}.
따라서 식~\eqref{eq:internalnorm}의 채널 내부 표준편차와 구분해야 한다.
이 표준화에는 클래스 가중치를 주지 않으며, 변환 후 배열은 float64로 넘긴다.
검증ㆍ테스트 사람에게도 학습 집합의 $m_{\mathcal I,k},a_{\mathcal I,k}$를 적용한다.

\subsection{클래스 가중 릿지의 정확한 목적함수}
$n_0=|\{i\in\mathcal I:y_i=0\}|$,
$n_1=|\{i\in\mathcal I:y_i=1\}|$라 하자.
각 $n_c>0$이며 참가자 $i$의 가중치는
\begin{equation}
 w_i=\frac{n}{2n_{y_i}},\qquad
 \sum_{i:y_i=0}w_i=\sum_{i:y_i=1}w_i=\frac n2.
\end{equation}
각 클래스의 손실 총 가중치를 같게 하며, 적합할 때마다 다시 계산한다.
$\alpha>0$에서 \code{RidgeClassifier}는 다음 문제를 푼다 \cite{ridge}.
\begin{equation}
 (b,\beta)=\argmin_{b\in\R,\,\beta\in\R^p}
 \left\{\sum_{i\in\mathcal I}w_i
 (r_i-b-\beta^\top\widetilde z_i)^2+\alpha\|\beta\|_2^2\right\}.
 \label{eq:ridge}
\end{equation}
절편 $b$에는 벌점을 주지 않는다. 합을 $n$으로 나누지 않은 규약이므로
평균 손실 목적함수로 바꿀 때는 벌점도 $\alpha/n$으로 바꿔야 같은 문제이다.
이는 이진 표적에 대한 가중 최소제곱 분류이며 로지스틱 손실이 아니다.

설계행렬을 $\widetilde Z\in\R^{n\times p}$,
$D=\operatorname{diag}(w_i)$, $\bm 1\in\R^n$, $r=(r_i)_{i\in\mathcal I}$라 하면,
정규방정식은
\begin{equation}
 \begin{bmatrix}
 \bm1^\top D\bm1&\bm1^\top D\widetilde Z\\
 \widetilde Z^\top D\bm1&\widetilde Z^\top D\widetilde Z+\alpha I_p
 \end{bmatrix}
 \begin{bmatrix}b\\\beta\end{bmatrix}
 =\begin{bmatrix}\bm1^\top Dr\\\widetilde Z^\top Dr\end{bmatrix}.
 \label{eq:normal}
\end{equation}
임의의 $a\in\R,v\in\R^p$에 대해 이 행렬의 이차형식은
$\|D^{1/2}(a\bm1+\widetilde Zv)\|_2^2+\alpha\|v\|_2^2$이다.
이 값이 0이면 먼저 $v=0$, 그 다음 $a=0$이다.
따라서 $p>n$이어도 해는 유일하다.
이는 수학적 유일성 설명이며 구현이 $p\times p$ 역행렬을 직접 만든다는 뜻은 아니다.

\subsection{결정 점수와 고정 임계값}
새 참가자의 점수와 분류는
\begin{equation}
 s_{\mathcal I}(X)=b+\beta^\top S_{\mathcal I}(z(X)),\qquad
 \widehat y(X)=\ind\{s_{\mathcal I}(X)>0\}.
\end{equation}
정확히 0인 점수는 PD이다.
이 실수 마진은 ET 확률이 아니며, sigmoid를 붙인다고 자동 보정되지 않는다.
임계값 0은 외부 평가 전에 고정했고 외부 정답으로 최적화하지 않았다.

\section{참가자 단위 5중ㆍ3중 중첩 교차검증}
\subsection{외부ㆍ내부 집합과 고정 특징 캐시}
외부 테스트 집합을 $\mathcal T_1,\ldots,\mathcal T_5$라 하자.
이들은 서로 겹치지 않고 합집합이 $\mathcal P$이다.
$k$번째 외부 학습 집합은 $\mathcal A_k=\mathcal P\setminus\mathcal T_k$이다.
각 $\mathcal A_k$를 내부 검증 집합
$\mathcal V_{k1},\mathcal V_{k2},\mathcal V_{k3}$로 분할하고
$\mathcal B_{kj}=\mathcal A_k\setminus\mathcal V_{kj}$를 내부 학습 집합으로 둔다.
모든 분할은 PD/ET 비율을 고려한 계층화 분할이며,
master seed는 20261017, 반복 수는 1이다.
기존 기준 모델과 전체 외부ㆍ내부 참가자 배정이 정확히 일치한다.
이 문서의 ``외부''는 중첩 교차검증의 outer fold를 뜻하며,
다른 기관에서 수집한 독립 코호트를 뜻하지 않는다.

각 $z_i$는 고정된 $X_i$와 $\theta_*$에만 의존하므로 전체 코호트에서 한 번 계산한다.
평가 모드는 dropout을 끄고, 인코더에는 다른 참가자의 배치 통계를 갱신하는 단계가 없다.
반면 $S_{\mathcal P}$를 먼저 적합하여 모든 폴드에 재사용하면
테스트 특징 분포를 학습에 반영하므로 이 프로토콜을 위반한다.
PCA, 학습형 채널 축소나 미세조정을 추가하면 그것도 각 학습 집합 안에서 적합해야 한다.

\subsection{내부 선택에서 외부 예측까지}
후보 집합은
\begin{equation}
 \mathcal H=\{10^{-3},10^{-2},10^{-1},1,10,100,1000\}
\end{equation}
이다. 각 외부 폴드 $k$에서 다음을 수행한다.
\begin{enumerate}
\item 각 내부 폴드 $j$마다 $S_{\mathcal B_{kj}}$를 새로 적합한다.
모든 $\alpha\in\mathcal H$에 대해 $\mathcal B_{kj}$에서 식~\eqref{eq:ridge}를 적합하고
$\mathcal V_{kj}$를 예측한다. 같은 내부 폴드 안에서는 고정 특징과 표준화를 후보 간 재사용한다.
\item 후보별 내부 균형 정확도 평균
$M_k(\alpha)=\frac13\sum_{j=1}^{3}\BA_{\mathcal V_{kj}}(\alpha)$를 계산한다.
$M_k^*=\max_{\alpha\in\mathcal H}M_k(\alpha)$에 대해
\begin{equation}
 \widehat\alpha_k=\max\{\alpha\in\mathcal H:
 |M_k(\alpha)-M_k^*|\le10^{-12}\}
\end{equation}
로 정한다. 따라서 수치적으로 동률이면 더 큰 $\alpha$를 택한다.
\item 내부에서 적합한 표준화와 분류기를 그대로 사용하지 않고,
$S_{\mathcal A_k}$와 선택된 $\widehat\alpha_k$의 릿지를
$\mathcal A_k$ 전체에서 새로 적합한다.
\item $\mathcal T_k$의 각 참가자에게 한 번만 점수를 준다.
그 외부 정답은 $\widehat\alpha_k$, 표준화 또는 임계값 결정에 사용하지 않는다.
\end{enumerate}
결과적으로 모든 참가자에게 외부 예측이 정확히 하나 있다.
내부 검증 점수는 선택용 자료이므로 최종 테스트 성능으로 보고하지 않는다.

\subsection{전체 코호트 최종 적합은 별도 산출물}
외부 평가가 끝난 뒤 전체 304명에 대해 별도의 3중 내부 탐색을 수행하고,
선택된 $\alpha=1000$으로 최종 표준화와 릿지를 적합했다.
\code{final_model.joblib}는 이 최종 모델을 담는다.
그 모델은 모든 참가자의 라벨을 보았으므로, 그 사람들에 대한 재예측을
외부 성능으로 해석하지 않는다. 최종 모델과 외부 폴드별 모델은 다른 객체이다.

\section{평가 지표의 정의와 실제 결과}
\subsection{혼동행렬과 불균형 자료의 지표}
ET를 양성으로 두고 TN은 PD를 PD로, FP는 PD를 ET로,
FN은 ET를 PD로, TP는 ET를 ET로 분류한 사람 수이다.
혼동행렬은 실제 클래스가 행, 예측 클래스가 열이며 순서는 $[\mathrm{PD},\mathrm{ET}]$이다.
\begin{align}
 \operatorname{Recall}_{\mathrm{ET}}&=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FN}},&
 \operatorname{Recall}_{\mathrm{PD}}&=\frac{\mathrm{TN}}{\mathrm{TN}+\mathrm{FP}},\\
 \BA&=\frac12\left(\operatorname{Recall}_{\mathrm{ET}}+
                         \operatorname{Recall}_{\mathrm{PD}}\right),&
 \operatorname{Precision}_{\mathrm{ET}}&=\frac{\mathrm{TP}}{\mathrm{TP}+\mathrm{FP}}.
\end{align}
일반 정확도는 $(\mathrm{TN}+\mathrm{TP})/N$이다.
모든 참가자를 PD라 예측해도 $276/304=90.79\%$이므로,
일반 정확도만으로 소수 ET의 탐지를 평가하면 오해할 수 있다.
항상 PD인 분류기의 균형 정확도는 50\%, ET 재현율은 0이다.

점수 순위를 평가하는 AUROC는
\begin{equation}
 \operatorname{AUC}=\frac1{N_1N_0}
 \sum_{i:y_i=1}\sum_{j:y_j=0}
 \left(\ind\{s_i>s_j\}+\tfrac12\ind\{s_i=s_j\}\right)
\end{equation}
이다. $N_1=28,N_0=276$이다.
ET average precision(AP)는 높은 점수부터 포함할 때의 재현율 증가량과
그 지점의 정밀도의 곱을 합한
$\operatorname{AP}=\sum_m(R_m-R_{m-1})P_m$이다.
동점 점수는 함께 처리하며 단순 PR 사다리꼴 면적과 구분한다.
코호트 ET 비율 $28/304\simeq0.0921$은 PR 그림의 비교 기준이다.

표~\ref{tab:metrics}는 각 참가자에 대한 외부 예측 1개씩, 총 304건으로 계산했다.
같은 참가자ㆍ라벨ㆍ분할ㆍ후보 집합ㆍ클래스 가중ㆍ임계값을 사용했다.
기준 모델의 특징 변환은 폴드 안에서 적합되며,
MantisV2 특징은 외부 사전학습 인코더로 고정된다는 차이가 있다.

이번 결과를 ``전 지표 우월''이라고 요약하면 틀리다.

\section{MPS 실행, 수치 검증과 재현성}
\subsection{GPU가 수행한 부분과 CPU가 수행한 부분}
이번 실행은 Apple MPS GPU에서 float32로 인코더 특징을 계산했다.
전체 채널 레코드 수는 $304\times132=40{,}128$개이며 배치 크기는 128이다.
특징 열 표준화와 릿지는 CPU에서 수행하고, CPU thread 수는 4로 제한했다.
특징 추출은 21.71초, 추출ㆍ중첩 평가ㆍ최종 적합은 29.45초였다.
설치와 체크포인트 다운로드 시간은 제외한다.
실행 기록의 특징 추출 시간에는 체크포인트 로드와 출력 구성도 포함된다.
전체 CPU 재실행 시간을 측정하지 않았으므로 이 값에서 일반적인 GPU 가속 배수를 도출하지 않는다.
이 기기에서 CUDA는 사용할 수 없었다.

전체 실행 전에 실제 채널과 0 상수 채널을 포함한 작은 배열
$(3,4,976)$에서 CPU/MPS 특징을 비교했다.
모든 GPU 특징은 유한했고, 최대 절대 차이는 $2.8610\times10^{-6}$,
상대 $\ell_2$ 차이는 $2.0987\times10^{-7}$이었다.
이는 테스트한 배열의 수치적 일치 근거이며 전체 CPU 평가의 복제가 아니다.

\begin{lstlisting}
.venv-transformer/bin/python -m sota_pd_et.evaluate_transformer \
  --output artifacts/pads_mantis_v2_reproduction \
  --device mps --batch-size 128 --threads 4 --fit-final

새 환경의 설치 명세는 \code{sota_pd_et/requirements-transformer.txt},
상세 안내는 \code{sota_pd_et/TRANSFORMER_README.md}에 있다.
MPS가 없으면 \code{--device cpu}, 지원하는 NVIDIA/PyTorch 환경이면
\code{--device cuda}를 지정한다.
기존 산출물 디렉터리를 덮어쓰지 않는다.

최종 분류기를 새 참가자에게 적용하려면 공식 전처리와 동일한 채널 순서의
$(132,976)$ 배열이 필요하다.
저장 인코더 설정과 체크포인트로 특징을 추출한 후,
저장된 scaler와 ridge를 순서대로 적용한다.
임의의 원시 녹음을 곧바로 넣거나, 저장 코호트 특징 행을 새 사람의 특징으로 대체하면 안 된다.

\section{해석의 범위와 남은 문제}
\begin{enumerate}
\item \textbf{개선은 제한적이다.}
ET 재현율이 늘었지만 28명 중 16명은 여전히 PD로 분류했다.
AUROC 감소를 포함하여 지표별 결과를 함께 해석해야 한다.
\item \textbf{탐색적 비교이다.}
기준 모델 결과를 이미 확인한 코호트에서 추가 모델을 시도했다.
동일 분할은 비교의 대응성을 높이지만 새 외부 코호트를 만들지는 않는다.
\item \textbf{정규화 탐색의 경계가 남는다.}
모든 외부 폴드와 최종 적합이 $\alpha=1000$을 선택했다.
이는 후보 집합의 상한이므로, 최적의 정규화 강도가 범위 안에 있다고 확립하지 못한다.
외부 결과를 보고 후보 범위를 바꾼 새 실행도 추가 탐색으로 기록해야 한다.
\item \textbf{표현의 제한이 있다.}
보간은 고주파 정보와 시간 해상도를 바꾸며 원시 시간 결손을 복원하지 않는다.
동결 인코더와 가법적 선형 헤드는 교차 채널 비선형 상호작용을 직접 학습하지 않는다.
\item \textbf{사전학습의 범용성과 PD/ET 최상위 성능은 별개이다.}
합성 시계열 사전학습과 일반 분류 벤치마크 근거는
이 코호트에서의 최고 성능이나 임상적 진단 성능을 증명하지 않는다.
\item \textbf{확률 보정ㆍ외부 검증은 수행하지 않았다.}
점수는 확률이 아니며, 이 연구는 외부 기관ㆍ전향적 코호트에서의
진단 효용이나 임상적 안전성을 확립하지 않는다.
\end{enumerate}
